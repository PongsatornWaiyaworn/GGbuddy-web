# 🎮 GGbuddy - หาเพื่อนเล่นเกมไปด้วยกัน  
[ggbuddy.onrender.com](https://ggbuddy.onrender.com/)

GGbuddy คือเว็บแอปที่สร้างขึ้นเพื่อให้เกมเมอร์ได้หาเพื่อนใหม่ที่เล่นเกมเดียวกัน สนุกไปด้วยกัน และสร้างคอมมูนิตี้เล็ก ๆ ที่อบอุ่น โดยคุณสามารถสร้างโปรไฟล์ แชท และค้นหาคนที่ชอบเกมเดียวกับคุณได้ในไม่กี่คลิก

---

## ลิงก์  
- 🌐 เว็บไซต์: [https://ggbuddy.onrender.com](https://ggbuddy.onrender.com)  

---

## 💡 ฟีเจอร์หลัก  
-  ระบบหาเพื่อนเล่นเกมตามเกมที่ชอบ   
-  ระบบแชท
-  บล็อคผู้ใช้ที่ไม่ชอบ
-  โปรไฟล์ผู้ใช้ที่สามารถตั้งค่าได้เอง 
-  ระบบล็อกอิน/สมัครสมาชิก

---

## ⚙️ Tech Stack ที่ใช้
- **Frontend**: React.js + TypeScript, Tailwind CSS  
- **Backend**: Go (Golang)  
- **Realtime Communication**: Socket.io 
- **Database**: MongoDB  
- **Authentication**: JWT (JSON Web Token)  
- **Deploy**: Render.com
